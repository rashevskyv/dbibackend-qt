# План реалізації - Вибір режиму додавання папок (як є або сканування)

Ця зміна додає запит до користувача при додаванні папки: додати папку як є (збереження ієрархії) або просканувати її на сумісні інсталяційні файли (плоский список). Відповідно до вибору змінюється відображення у списку та робота HTTP/FTP серверів.

## Необхідно переглянути користувачу

> [!IMPORTANT]
> - При виборі "Додати як є" папка відображається у списку як один елемент. Браузери та FTP-клієнти бачать її як директорію та можуть переходити всередину. DBI-клієнт також бачить структуру папок, але всередині відображаються лише сумісні Switch файли.
> - При виборі "Просканувати" папка сканується, і всі сумісні файли додаються як плоский список до кореня.

## План перевірки

### Автоматизовані тести
- Запуск `python main.py`.

### Ручна перевірка
- Додати папку через кнопку "Add folder" та обрати "Add as is". Перевірити, що папка з'явилася як один рядок.
- Додати папку та обрати "Scan". Перевірити, що файли додалися плоским списком.
- Перевірити навігацію по віртуальних папках через браузер та FileZilla.
- Перевірити відображення сумісних файлів усередині папок на Switch DBI.
