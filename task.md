## Відкрите

- [ ] 2.9.3: консоль у MTP (Kefir Hub 0.14.038+), запустити USB-сервер → на консолі запит про PC Install (USB); «PC Install (USB)» → бекенд підключається; «No» → MTP лишається, запит не повторюється; libusb у Windows має бачити PID 201D без драйвера WinUSB (інакше в журналі нічого немає — тоді перевірка через Shell замість libusb).
- [ ] Windows без Zadig: чистий ПК (або видалений драйвер), підключити консоль у PC Install (USB), запустити бекенд → запит → UAC → WinUSB → консоль підключається й встановлює пакунок.
- [ ] Windows, де libusbK уже поставлено Zadig: запиту немає, бекенд підключається через libusbK.
- [ ] Відмова в UAC: зрозуміле повідомлення, повтор через Help > Install USB Driver.
- [ ] Зібрати exe (`build.bat`) і перевірити, що в ньому є `libusb-1.0.dll` та `src/install_winusb.ps1`.
- [ ] Linux: правило udev через `pkexec`, підключення без root.
- [ ] Повний USB і папковий сценарії на фізичному Switch, смуги пам'яті під час встановлення.
