# Звіт про виконані зміни (Walkthrough) - Версія 2.7.0

Усі заплановані роботи завершено та успішно впроваджено. Нова версія додатку: **2.7.0**.

## Зміни, що були внесені:

1. **Діалогове вікно вибору режиму додавання папки:**
   - При додаванні папки через інтерфейс (кнопка "Add folder"), Drag & Drop або зовнішній запуск, тепер з'являється діалогове вікно-запит:
     - **Add as is (Hierarchical):** папка додається як один ієрархічний елемент. Мережеві сервери HTTP/FTP відображають структуру папок, даючи змогу користувачу здійснювати навігацію.
     - **Scan for Switch files (Flat):** папка рекурсивно сканується, і всі знайдені сумісні файли додаються до списку окремими плоскими елементами.

2. **Оновлення USB-режиму:**
   - Для запобігання помилкам передачі при виборі папок "як є", клас `USBHandler` автоматично сплощує папки при ініціалізації та формує плоский перелік сумісних Switch файлів перед початком передачі.

3. **Оновлення HTTP та FTP серверів:**
   - Сервери переведено на повністю ієрархічну модель для обох типів клієнтів (як DBI, так і браузери/FTP-клієнти).
   - Коли клієнтом є Switch DBI: сервери автоматично фільтрують вміст будь-якої віртуальної папки, відображаючи виключно сумісні Switch файли (`.nsp`, `.nsz`, `.xci`, `.xcz`) та вкладені папки.
   - Коли клієнтом є звичайний браузер або FTP-клієнт (наприклад, FileZilla): сервери відображають абсолютно всі файли без розрізнення розширень.

## Результати перевірки та тестування:
- Додаток успішно запускається та працює без помилок.
- Проведено успішне збирання standalone виконуваного файлу через `build.bat`.
