# Аудит

Стан на 09.10.2026, версія 2.9.4. Лише поточний стан і межі доказів; історія — у [walkthrough.md](walkthrough.md).

## Перевірено локально

88 pytest тестів (`pytest -n auto`), імпорт UI у Windows, `compileall` у Windows і WSL (WSL без PyQt6, тож UI там не запускався). Головне вікно відрендерено й переглянуто в обох темах. Для Sphaira v0.13.901 пройшли сім цільових Python контрактів; C++ збірку не запускали.

| Область | Що підтверджено |
| --- | --- |
| Смуги сховища, ETA | Кольори й 3-метричний формат (+written / package_size / free) звірено з `draw_storage_bar` і `FormatEta` у Sphaira. Текстова ширина адаптивна. |
| Черга та контекстне меню | Переміщення "Set as Next in Queue" розміщує вибрані файли/папки одразу за активними; захист завершених/активних файлів підтверджено тестом. |
| Target, повторний metadata FileRange | Done не скидається; прогрес рядка видно крізь Target. |

## Відомі обмеження

- **Встановлення драйвера не запускалося**: імпорт сертифіката в Root і `pnputil` на цьому ПК заборонені середовищем агента. Потрібна ручна перевірка на консолі (див. task.md). Збірку exe теж не виконано.
- Якщо драйвер поставлено без підключеної консолі, запит при старті повторюється, доки консоль не підключать.
- Кожне встановлення додає ще один кореневий сертифікат (без приватного ключа).
- Інсталятор з правами адміністратора дописує лог у `%TEMP%` користувача; підміна цього шляху посиланням теоретично можлива.
- ns-usbloader і Fluffy з драйвером WinUSB не перевірялися; документація лишає для них Zadig/libusbK.

- Фізичний Switch не перевірено: USB цикл, папкова передача, SPHQ/SPHA, жива черга, смуги під час встановлення.
- Стрілка Target рендериться прямокутником, а не трикутником (CSS-бордери).
- Для цілі Auto backend вгадує накопичувач для жовтого сегмента; рішення приймає Sphaira (`PlanPickSd`).
- Сегмент рахує байти файла на ПК, а не розпакований розмір NSZ.
- Вікно швидкості: backend 30 с, Sphaira ~48 с — ETA трохи розходяться.
- `switch_storage_label` прихований і лишився лише заради старого тесту.
- Перевірку мишею й різні DPI у Windows не виконано.

Користувацькі пресети й резервні копії в робочому дереві не чіпати.
