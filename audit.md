# Аудит

Стан на 02.10.2026, версія 2.9.0. Лише поточний стан і межі доказів; історія — у [walkthrough.md](walkthrough.md).

## Перевірено локально

51 pytest тест (`pytest -n auto`), імпорт UI у Windows, `compileall` у Windows і WSL (WSL без PyQt6, тож UI там не запускався). Головне вікно відрендерено й переглянуто в обох темах. Для Sphaira v0.13.901 пройшли сім цільових Python контрактів; C++ збірку не запускали.

| Область | Що підтверджено |
| --- | --- |
| Смуги сховища, ETA | Кольори й формат звірено з `draw_storage_bar` і `FormatEta` у Sphaira. |
| Target, повторний metadata FileRange | Done не скидається; прогрес рядка видно крізь Target. |
| Черга папок | Ієрархія, пакетний вибір режиму, конфлікти basename, пресети. |
| USB range, статуси | Неповна передача не вважається завершеною; переходи Done/Skipped/Failed узгоджені. |
| SPHQ і жива черга | Порядок, ревізія, порожній старт, ACK; legacy DBI/SPHA без ревізій. |
| USB-драйвер (2.9.0) | Вбудований libusb-1.0 знаходиться; консоль без драйвера дає `NotImplementedError` (перевірено на інших пристроях без драйвера); перебір бекендів і класифікація помилок покриті `tests/test_usb_driver.py`; INF і каталог генеруються, `Test-FileCatalog` = Valid; скрипт синтаксично коректний; реєстр цього ПК (18 консолей на libusbK) → запиту немає. |

## Відомі обмеження

- **Встановлення драйвера не запускалося**: імпорт сертифіката в Root і `pnputil` на цьому ПК заборонені середовищем агента. Потрібна ручна перевірка на консолі (див. task.md). Збірку exe теж не виконано.
- ns-usbloader і Fluffy з драйвером WinUSB не перевірялися; документація лишає для них Zadig/libusbK.

- Фізичний Switch не перевірено: USB цикл, папкова передача, SPHQ/SPHA, жива черга, смуги під час встановлення.
- Стрілка Target рендериться прямокутником, а не трикутником (CSS-бордери).
- Для цілі Auto backend вгадує накопичувач для жовтого сегмента; рішення приймає Sphaira (`PlanPickSd`).
- Сегмент рахує байти файла на ПК, а не розпакований розмір NSZ.
- Вікно швидкості: backend 30 с, Sphaira ~48 с — ETA трохи розходяться.
- `switch_storage_label` прихований і лишився лише заради старого тесту.
- Перевірку мишею й різні DPI у Windows не виконано.

Користувацькі пресети й резервні копії в робочому дереві не чіпати.
