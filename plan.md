# План

Стан на 09.10.2026, версія 2.9.3. Користувацькі пресети й резервні копії в робочому дереві не чіпати.

## Наступні кроки

1. Перевірити встановлення USB-драйвера на Windows із консоллю: чистий ПК, ПК із libusbK від Zadig, відмова в UAC (сценарії в task.md). Зібрати exe і переконатися, що в ньому є `libusb-1.0.dll`.
2. Перевірити повний USB і папковий сценарії на фізичному Switch із Sphaira/DBI: смуги сховища, подвійний ETA, живу чергу, повторне metadata читання встановленого файла.
3. Перевірити UI у Windows з мишею, різними масштабами DPI і віконними режимами.
4. За бажанням: замінити стрілку Target на картинку; не малювати сегмент встановлення для Auto або передавати обрану ціль у протоколі; видалити `switch_storage_label` разом зі старим тестом.

Докази й обмеження: [audit.md](audit.md). Зміни за версіями: [walkthrough.md](walkthrough.md). Задачі: [task.md](task.md).
