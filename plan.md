# План

Стан на 02.10.2026, версія 2.8.5. Користувацькі пресети й резервні копії в робочому дереві не чіпати.

## Наступні кроки

1. Перевірити повний USB і папковий сценарії на фізичному Switch із Sphaira/DBI: смуги сховища, подвійний ETA, живу чергу, повторне metadata читання встановленого файла.
2. Перевірити UI у Windows з мишею, різними масштабами DPI і віконними режимами.
3. За бажанням: замінити стрілку Target на картинку; не малювати сегмент встановлення для Auto або передавати обрану ціль у протоколі; видалити `switch_storage_label` разом зі старим тестом.
